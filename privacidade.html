Política de Privacidade — Sagas Publisher

Última atualização: 21 de outubro de 2026.

O Sagas Publisher é uma ferramenta interna, usada apenas pelo responsável pelo perfil @sagasdabiblia, para publicar no TikTok vídeos originais produzidos por nós.

Dados que acessamos

Ao conectar a nossa própria conta do TikTok, a ferramenta recebe apenas o que a API do TikTok fornece para publicar: informações básicas do perfil (nome e identificador) e um token de acesso. Não coletamos dados de outros usuários, seguidores ou espectadores.

Uso dos dados

Os dados são usados exclusivamente para enviar e publicar os nossos vídeos na nossa conta. Não vendemos, não compartilhamos e não usamos esses dados para publicidade.

Armazenamento

O token de acesso fica guardado somente no computador do responsável, e pode ser revogado a qualquer momento nas configurações do TikTok (Segurança → Apps com permissão).

Contato

Dúvidas: mensagem direta para @sagasdabiblia no TikTok.

Privacy Policy (English)

Sagas Publisher is an internal tool used only by the owner of the TikTok account @sagasdabiblia to publish our own original videos. It only receives the basic profile information and access token provided by the TikTok API for our own account, uses them solely to upload and publish our videos, stores the token only on the owner's computer, and never collects, sells or shares data of any other user. Access can be revoked at any time in TikTok settings. Contact: direct message to @sagasdabiblia on TikTok.
